# Contributing to Oripo

Use the Node release in `.nvmrc` and the npm version in `package.json`. Install with `npm ci`, then run `npm run dev`. English lessons live under `/en/lessons/`. The [README](README.md#verify-changes) lists the browser setup and all quality commands.

For a new lesson, record the exact source, adaptation rights, maker difficulty, paper proportions, moving plies and independent finished landmarks. A draft package and its localized copy supply the public catalog, route data, studio and preview. Keep stable action IDs and include the expected result of each fold. Follow the [authoring guide](docs/authoring.md) for the CLI, interchange subset, motion boundaries, font coverage and publication checks.

Use independent geometry and production pixels to test the transition as well as the endpoint. State which manual reviews are outstanding. A new technique needs a reproducible analytic fixture before a lesson uses it. [Construction decisions](docs/phase-9-candidates.md)

Before submitting, run typecheck, lint, formatting, unit tests, the production build and the full browser matrix. Keep each Conventional Commit focused. Describe what a reader can now do, the commands you ran and any device or paper checks still open. Capture demos from the production build using the actual player. Keep local logs and screenshots under ignored `.local/`.
