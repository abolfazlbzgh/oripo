# Contributing to Oripo

Use the Node release in `.nvmrc` and the npm version in `package.json`. Install with `npm ci`, then run `npm run dev`. English lessons live under `/en/lessons/`. The [README](README.md#verify-changes) lists the browser setup and all quality commands.

For a lesson, start with a paper size, named landmarks, moving plies and an observable result for every action. Give the model and its steps stable IDs. Keep the English manuscript and each localized transcript keyed by the same step IDs. Straight folds that end flat use the packet helper. Models with a spatial finish can use the same pattern compiler directly. Bind the model to the shared player, register its catalog entry and shared route module, then test the production page before listing it in the catalog. See the [authoring guide](docs/architecture.md#adding-the-next-lesson).

Register the maker difficulty and category independently of the route ID. Choose front, reverse and edge pigments for the finished stock, then bind the endpoint mesh and preview camera in `scripts/lesson-previews.ts`. The build projects the thumbnail. Register the English source in `app/i18n/catalog.server.ts`. Add the model title, short name and summary to each `common.json`, and supply each locale's starting sheet and every stable step with a title, instruction and result. Regenerate the script-specific font subsets for new characters and record human review status. The Masu example covers coupled corner folds and material layer ordering. [Geometry and appearance contract](docs/decisions/0007-coupled-corners-and-finished-paper.md)

Use independent landmarks or silhouettes to check geometry, including a mid-fold pose, the final outline and the full return to flat. Check keyboard controls, text-only instructions and renderer cleanup when changing the studio. Credit the source and permission for any imported asset or diagram.

For a waterbomb, a pinned pocket or a herringbone grid, split the material along the moving seams and start with a small version 3 analytic fixture. Supply a whole-sheet `field` or assign individual `regions` to named material faces. Share the compiled model, eye position and virtual layer settings between the studio and the preview generator. Run `npm run build` to produce the endpoint PNG. The full frog and map tests demonstrate 1,001 poses per action, independent clearance and stacking probes, collision sampling and 1,000 reversals. [Field parameters and worked constructions](docs/decisions/0008-intermediate-constructions.md) · [Build and verification commands](README.md#verify-changes)

Before submitting, run typecheck, lint, formatting, unit tests, the production build and the full browser matrix. Keep each Conventional Commit focused. Describe what a reader can now do, the commands you ran and any device or paper checks still open. Capture demos from the production build using the actual player. Keep local logs and screenshots under ignored `.local/`.
