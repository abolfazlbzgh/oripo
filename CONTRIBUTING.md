# Contributing to Oripo

Clone the repository using its GitHub clone URL, enter the checkout and create a topic branch, for example `git switch -c feat/lesson-draft`. Keep your own contributor identity. Use Node 22.23.2 and npm 10.9.8 with `npm ci --strict-peer-deps` and `npm run dev`. [Quickstart and quality commands](README.md)

For a lesson, start with the exact construction, rights, stock proportions, accessible plies and independent landmarks. Develop a draft in `models/<slug>/lesson.json`. Keep stable action IDs and provide an observable result for each fold. The geometry compiler is independent of React. Code for a new motion belongs there when independent fixtures establish its domain. [Model contract and CLI](docs/authoring.md) · [Engine source map](docs/architecture.md)

Run the package checks, typecheck, lint, formatting, unit tests, static build and three-browser suite. Check the actual studio when changing motion or appearance. Keep local captures under `.local/`. In a focused pull request, explain the change, reference/asset rights, independent checks, commands executed and any pending physical or language review. Use small Conventional Commits and include the generated indexes when catalog metadata changes. [Release checklist](docs/release.md) · [Security reporting](SECURITY.md)
