# Architecture

## Trace a lesson

1. **Validate and register.** The CLI discovers `models/<slug>/lesson.json`, checks its schema, sheet, motion, drawing configuration and localized manuscripts. It generates a small metadata index for the gallery and a separate lazy loader map for published model packages. The navigation registry expands published slugs across locales. [Validator](../scripts/validate-package.ts) · [Catalog generator](../scripts/model-catalog.ts) · [Navigation](../app/navigation.ts)
2. **Prerender.** The root loader selects the locale and teaching text. The shared lesson route reads a package's action IDs and durations for the transport. React Router emits HTML and static route data. A visitor can read the instructions with JavaScript disabled. [Root document](../app/root.tsx) · [Lesson route](../app/routes/lesson.tsx) · [Static configuration](../react-router.config.ts)
3. **Compile.** The client imports one package and compiles its material graph into indexed vertices, convex faces and shared edges. The compiler resolves each step from the preceding endpoint, checks motion ownership and seams, and caches endpoints. `poseAt` samples the prepared action at absolute progress. The engine has no DOM or rendering dependency. [Scene entry point](../app/lesson/package-scene.client.ts) · [Compiler](../app/lesson/geometry.ts)
4. **Draw.** Playback maps time and commands to an absolute step and fraction. Material vertices use ideal hinges. `paperLayers` transports virtual offsets separately so touching sheets draw in order. The scene uses the teaching palette until the final boundary, switches to the package's `finishedAppearance` at completion and restores teaching colors on reversal. Sparse instructional views share the command clock. The camera orbits while the paper holds at the boundary, then the scored edges follow their incident drawing plies. [Guided views decision](decisions/0012-guided-instructional-views.md) [Transport](../app/lesson/playback.ts) · [Layers](../app/lesson/drawing.ts) · [Scene](../app/lesson/lesson-scene.client.tsx)
5. **Project.** At build time the gallery projector applies the same compiler, layer settings, palette and preview eye to rasterize the finished mesh. Gallery visits request a static PNG. [Preview generation](../scripts/lesson-previews.ts) · [Rasterizer](../scripts/paper-preview.ts)

In the Dart's `mark-spine`, eight faces rotate together about the directed nose-to-tail axis. The Masu box uses that same turn path for rigid walls. Its bisected corners add a nonlinear local rotation and optionally a wall carrier, evaluated together so the corner follows both boundaries. The material and drawing share this ordered transform with different pivot origins. Waterbombs, pocket squashes, herringbone, spatial crimps, hex twists and double-boat pockets keep their own analytic constraints. A chart maps a rigid face's origin and basis at a given progress. Incident charts must agree on shared material vertices. The tray corner solves its common diagonal from both wall angles. A framed boat pocket carries the local chart and its display normal into the current material plane. [Dart package](../models/paper-airplane/lesson.json) · [Masu package](../models/masu-box/lesson.json) · [Versioned package decision](decisions/0010-declarative-lessons.md) · [Framed pockets and tray corners](decisions/0011-framed-pockets-and-tray-corners.md)

## Documents and verification

Explore, Guide and lesson pages share the localized shell, appearance controls, reading direction and font selection. Each canonical page has ten language alternatives. The English root alias and internal first-fold lab are also prerendered. Locale-specific error documents preserve the response status and link back to the gallery. [Localized documents decision](decisions/0006-localized-static-shell.md) · [Static output](../scripts/static-files.ts) · [Preview server](../scripts/preview.mjs)

Geometry tests compare welded seams, panel lengths, independently derived landmarks, sampled collisions and approaching layer order. Browser tests inspect pixels from the actual scene and gallery, including intermediate views, reversal and failure recovery. Historical decisions retain the rationale for specific constructions.
