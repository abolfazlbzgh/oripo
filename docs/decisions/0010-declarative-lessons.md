# ADR 0010 · Versioned lesson packages

One model directory owns the lesson ID, physical pattern, presentation, publication state, catalog order and provenance. Package version 1 contains the normalized material graph and steps accepted by engine versions 1–5. Both versions travel with the data. Localized manuscripts use the same stable model and step IDs. Compiled closures and sampled poses exist only in memory.

The authoring CLI generates deterministic public metadata. Dev, build and CI validate the packages, manuscripts and generated indexes. Explore and Guide read a small index. A single lesson route requests one transcript and one model's timing. Its client-only scene loads that model's data on demand. Preview projection and playback use the same sheet, rotations, layer settings and finished pigments. Drafts have no public registration.

FOLD interchange covers a planar material graph. Sequential changes of hinge sense, selected plies, text, display layers and cameras belong to the native lesson. Imported topology begins as a draft. A published construction needs an independent fold plan, physical landmarks and sampled geometry checks.

The CLI, studio and preview resolve optional presentation settings through the same pure function. Stock-sized camera defaults and material-plane pivots handle simple open folds. Closing packets and coupled gussets require an authored contact order.

## Working checklist

- Freeze the Phase 8C inputs, drawing settings, translations, route enumeration, endpoint images and intermediate material/drawing poses before conversion.
- Verify all 123 actions against that capture, retain the independent model-specific tests and commit the migration before replacing a model.
- Exercise strict validation, material interchange, draft exclusion and addition of a supported construction using data alone.
- Assess the three exact visual references and record each publication decision. Run the local release gates on the resulting catalog.

The normalized step selects one typed preparation path for turns, whole-sheet fields, regional fields, current-pose crimps or retraces. Version 5 adds a regional double-boat pocket.
